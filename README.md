# AI.NLI
Естественно-языковой интерфейс для экспертных систем
Система для автоматического заполнения форм входа экспертных систем и обработки их выхода.

Форма входа представлена как массив полей, одно поле Yaml:

name:Имя_параметра
type:Тип_данных
description:Описание

Работает по принципу Actor-critic:
Actor заполняет, а critic проверяет все ли заполнено

Есть 3 режима, если в начальном сообщении не было информации и переход в (Дозаполнить по документам и web) ничего не дал: 
1. Спросить у пользователя (по-умолчанию)
2. Заполнить при помощи LLM (что понизит вероятность выводов по дозаполненым полям)
3. Незаполнять неизвестные поля
